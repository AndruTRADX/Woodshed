# Woodshed

This is a platform for all musicians, where they can shade their content, get feedback, interact, connect, all in just one platform.

This projects wants to be that `Woodshed` for musicians all over the world, made with love for the people who inspire us with their love for music.

I hope you folks enjoy it as much as I'm enjoying making it <3.
